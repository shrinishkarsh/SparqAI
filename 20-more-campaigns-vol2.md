# SparqLabs — 20 More Campaign Directions (Vol. 2)

Where Vol. 1 varied **Industry × Geo × ICP** on one core play ("we book you
meetings"), Vol. 2 deliberately pulls the levers that create *genuinely distinct*
campaigns — **new offer mechanisms, new personas, and new trigger engines** — so
each needs its own pain/offer/copy logic, not just a new list.

**Distinct-lever legend:** `OFFER` = new play/mechanism · `PERSONA` = new buyer in a
covered vertical · `TRIGGER` = new "why now" engine · `VERT/GEO` = untapped market.

**PROOF score** (max 55): **P**roof×3 · **R**eachability×2 · **O**ffer-fit×3 ·
**O**rder-value×2 · **F**riction(inverse)×1. Higher = run sooner.

## A. New OFFER / PLAY (warmer audiences, different value prop)

### 21 — CRM database reactivation `OFFER`  · PROOF 50
- **Industry / Vertical:** Horizontal B2B (SaaS, services, mfg) with aging CRMs
- **Location:** US / UK
- **ICP / Persona:** VP Sales / Head of Revenue / RevOps
- **Trigger:** 10k+ dormant CRM contacts, sales team focused only on net-new
- **List Logic:** B2B, 50–500 HC, HubSpot/Salesforce, large stale contact DB. *DQ:* <2yr-old companies. **Owned data — no sourcing.**
- **Pain Logic:** *Surface* — thousands of paid-for leads sitting dead. *Business* — CAC already spent, zero return on the backlog. *Personal* — VP under pressure to find pipeline without more budget.
- **Offer Logic:** *Dream* — pipeline from leads you already own. *Mechanism* — DFY reactivation sequences to dormant CRM. *Guarantee* — meetings-from-existing-data or free. *Packaging* — flat project + per-meeting.
- **Personalization Logic:** 1:few by last-touch reason / lifecycle stage.
- **Copy Angle:** Subj `your old leads` · "You've already paid to acquire thousands of contacts now sitting dead in {{tool_in_use}} — that backlog is the cheapest pipeline you'll ever get."
- **Variables:** `{{first_name}} {{company}} {{tool_in_use}} {{proof_metric}}`

### 22 — Closed-lost win-back `OFFER`  · PROOF 50

- **Location:** US / UK
- **ICP / Persona:** VP Sales / CRO
- **Trigger:** Deals lost 6–18mo ago (budget/timing/competitor) now cycling back
- **List Logic:** Companies with a closed-lost record, ICP-fit, where the original blocker likely expired. **Owned + light enrichment.**

- **Personalization Logic:** 1:few by lost-reason cohort (price / timing / competitor).
- **Copy Angle:** Subj `circling back, properly` · "When we last spoke the blocker was {{trigger_detail}} — that's usually expired by now, which is exactly when a second look makes sense."
